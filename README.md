# Website Profil Ajeng

Website profil pribadi sederhana dengan desain gradasi pink dan biru.

## Cara menjalankan
1. Download atau ekstrak folder ini.
2. Buka `index.html` di browser untuk melihat website.
3. Untuk GitHub Pages, buat repository baru di GitHub.
4. Upload file `index.html` ke repository.
5. Buka **Settings → Pages**.
6. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
7. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
8. Tunggu proses selesai. Alamat website akan muncul di halaman GitHub Pages.

## Catatan privasi
Nomor HP, email, dan alamat rumah lengkap tidak dimasukkan ke website publik. Sebaiknya jangan mempublikasikan data kontak pribadi atau alamat rumah secara terbuka, terutama pada repository publik.
